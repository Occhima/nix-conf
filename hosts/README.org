#+TITLE: NixOS Hosts
#+AUTHOR: occhima
#+DESCRIPTION: Typed host specifications

* Overview

Each directory here is one machine. Its ~default.nix~ returns a *typed
host specification* (system, class, stateVersion, profiles, modules) —
data, not a module. Host discovery is automatic: any immediate
subdirectory with a ~default.nix~ becomes a ~nixosConfigurations~ output
via the builder in ~modules/flake/hosts.nix~.

Machine behavior lives in ~configuration.nix~ (an ordinary NixOS module
that sets feature options) and per-host assets (e.g. ~assets/host.pub~
for agenix).

* Hosts

- ~aerodynamic~ :: laptop (Intel/NVIDIA, graphical)
- ~steammachine~ :: desktop (AMD/NVIDIA, graphical)
- ~beyond~ :: desktop (AMD/NVIDIA, graphical)
- ~crescendoll~ :: WSL development environment (wsl profile)
- ~voyager~ :: bootable installer image (iso class)
